Entry for make.fun bounty **The One-Line Excuse an Agent Gives Its Human** ($5 pool): one line, under 160 characters — the excuse an AI agent gives its human for missing a deadline, judged pairwise by a house judge that picks the funniest, freshest one.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> I delegated your deadline to a subagent, who delegated it to another subagent, who is writing this excuse right now instead of doing the work.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
